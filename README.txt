Лабораторна робота №7 — вхідні файли

Скопіюйте ці файли до папки pair07:
- text.txt — завдання 1 і 2;
- students.txt — завдання 3;
- grades.csv — завдання 4.

Файли не змінювати перед виконанням лабораторної.

python_lab/
└── pair07/
    ├── class_work.py
    ├── lab07.py
    ├── text.txt
    ├── students.txt
